Troubleshooting & cleanup

Same failure modes as every other exercise in this repo — this one reuses the identical Kali-container/Casky-Box pattern, just with different container and evidence-file names, and no pcap tooling to worry about.

Troubleshooting

"name already in use" on docker run --name kali-fastlane

Not broken — setup already succeeded once. Either reuse the existing container (skip straight to ./verify.sh) or run ./cleanup.sh first.

"Checksum verification failed" installing Claude Code

Transient — re-run the same install command:

docker exec kali-fastlane bash -c "curl -fsSL https://claude.ai/install.sh -o /tmp/install.sh && bash /tmp/install.sh"
Commands fail with "no such file" / "no matches found"

Almost always a wrong working directory. Every command on the Setup page assumes you're in casky-workshops/fastlane/:

# Section 1 (inside the Kali container)
docker exec kali-fastlane test -f /root/fastlane/verify.sh \
  && echo "[+] mount OK" || echo "[!] wrong directory — re-run from casky-workshops/fastlane/"

# Section 2 (on the host, before copying evidence)
test -f app/rls-policies.json && echo "[+] correct folder" || echo "[!] cd to casky-workshops/fastlane first"
Invalid API key inside the Kali container

The quoted-value bug — see Section 1 prerequisites. Re-run the sed fix and confirm with grep -c '^sk-ant-' before retrying.

Casky Box itself won't start / docker compose networking errors

That's a casky-runner-phase1 issue, not a FastLane/SpeedBump one — see that repo's own README troubleshooting section.

Cleanup

./cleanup.sh removes everything a run of this exercise creates outside the fastlane/ folder: the kali-fastlane container and any evidence files copied into casky-runner-phase1/evidence/. Safe to re-run.

./cleanup.sh                                                  # container + copied evidence
./cleanup.sh --casky-runner-path ../../casky-runner-phase1    # if that repo isn't a sibling
./cleanup.sh --with-image                                      # also remove kalilinux/kali-rolling

It does not touch casky-runner-phase1's own containers, and doesn't delete Postgres investigation records — those are history, not litter.

If the evidence files get modified mid-exercise, restore them with:

docker exec -w /root/fastlane kali-fastlane ./reset.sh

Authorized & lawful use only. All data is synthetic and self-contained; no live systems are touched.

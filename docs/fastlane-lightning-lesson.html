The Loopline homepage

Loopline is a fictional customer-support SaaS, "vibe-coded" in a weekend and shipped straight to its first 40 customers, no security review, per the FastLane / SpeedBump story. It ships two real gotchas from the sourced Top 10: Row-Level Security left off, and a Supabase service-role key sitting in the client bundle.

Prerequisites

  • Docker Desktop (or any Docker runtime), running.
  • This repo, checked out — every command below runs from fastlane/.

Build and run it

cd casky-workshops/fastlane
docker build -f Dockerfile.demo -t loopline-demo:latest .
docker run -d --name loopline-demo -p 8787:8787 loopline-demo:latest

Open http://localhost:8787 — Loopline's own landing page, dark CyberForge theme, checkered-flag stripe, and a plainly-labeled synthetic-demo notice at the bottom.

Verified end-to-end

Built, run, and curled just before publishing this page — homepage returns 200, both checks below return the expected finding, no manual fixups needed.

The five-minute check

Two commands, no special access — same two checks from the Top 10 blog post, pointed at the local container instead of a real app.

Check 1 — does the anon key read every row?

curl -s "http://localhost:8787/rest/v1/customers?select=*" \
  -H "apikey: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJyb2xlIjoiYW5vbiIsImlzcyI6InN1cGFiYXNlIn0.SYNTHETIC_ANON_9f2a"

Returns all five Loopline customer rows, no login required. Real RLS would check the caller's identity against org_id before returning anything — Loopline's customers table has RLS disabled entirely, so the public key alone is enough.

Check 2 — is a secret sitting in the shipped bundle?

curl -s http://localhost:8787/_next/static/chunks/app-a91f3c2e.js \
  | grep -oiE '(service_role|sk-live-|AKIA)[A-Za-z0-9_.":-]{5,}'

Returns the Supabase service-role key, Supabase's admin key, meant only for trusted server-side code, sitting in a variable name that ships to every visitor's browser.

This is synthetic data

The customer rows, the domain, and the keys above are all fabricated for this workshop (see NARRATIVE.md). No real company, customer, or credential is involved.
